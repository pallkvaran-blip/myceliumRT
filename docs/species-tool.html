Colonies & starting hands

Every colony in the roster, its opening hand, its Spore price, and which three open the campaign. Edits are kept in this browser as you make them — press Export when you are done and apply the JSON with the one command at the foot of the page.

Export & apply

Copy this and run, from the repo root:

pbpaste > /tmp/species.json && node scripts/apply-species.mjs /tmp/species.json

(or save the JSON anywhere and pass that path). The script rewrites index.html's SPECIES hands, STARTER_SPECIES_IDS, STORE_SPECIES_IDS and STORE_SPECIES_COST, and prints what it changed. It refuses rather than writing a half-applied file if anything does not line up.

What each field does in the game
Starter 1 / 2 / 3STARTER_SPECIES_IDS, in that order — the opening roster, free and playable from a fresh save. Exactly three; picking a slot another colony holds swaps the two.
StoreSTORE_SPECIES_IDS plus its price in STORE_SPECIES_COST. Visible from the start, bought with Spores; paying is the whole requirement — no level clear is involved.
LockedIn the roster but unobtainable: not a starter and not for sale. The tier machinery still exists, so a level clear still reveals one, but nothing on the selection screen can offer it.
Starting handEach colony's hand — the deck the run opens with, by card and number of copies. A name that is not a real card is flagged in red; the game would silently drop it.
Memorymemory: true — this colony hand-picks cards from the last run. Set in index.html, not here.
