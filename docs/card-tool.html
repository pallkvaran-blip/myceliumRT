Card tool

Every card currently in the game — not archived, and with an effect behind it. Edit the costs, the description, what the ledger says it produces, and how many copies the deck opens with. Export, then node scripts/apply-cards.mjs <file.json> writes it all back into index.html. Edits are kept in this browser as you type.

Descriptions that promise something new usually mean moving a number, not writing code. Each card lists the CONFIG.cards knobs its effect actually reads, with their current values — edit those here too. Where a rewrite needs behaviour that no knob can express, say so in the card’s note and it rides along in the export.
