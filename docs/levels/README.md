# Hand-authored levels

Maps in this folder replace the procedural generator for one level. Each file is a
`mycelium-level` JSON object — an explicit list of objects a designer placed, with world
geometry of its own. The loader is `engine/level.js` (`buildLevel`) inside `index.html`;
read its header comment for the object types, because **the unit conventions are not
uniform**: food `r` is a diamond radius in *cells*, reservoir `r` is *world units*, cloud
`r` is *cells*, and everything else is world units.

| file | level | what it is |
|---|---|---|
| `three-ways.json` | none (`#level,three-ways`) | "Three Ways Up" — three sealed routes, one threat each |
| `maze-one.json` | none (`#level,maze-one`) | "Maze One" — **traced**: 77 sprites from `docs/maps/maze-1@4x.webp`, dense with tight channels |
| `scatter-one.json` | none (`#level,scatter-one`) | "Scatter One" — **traced**: 25 sprites from `docs/maps/scatter-1@4x.webp`, open with big separated masses |
| `scatter-two.json` | none (`#level,scatter-two`) | "Scatter Two" — **traced**: 38 sprites from `docs/maps/silhouette-2@4x.webp` (the `scatter` prompt under its old name) |
| `ledges-one.json` | none (`#level,ledges-one`) | "Ledges One" — **traced**: 8 long slabs at 25% solid, the most open map |
| `veined-one.json` | none (`#level,veined-one`) | "Veined One" — **traced**, and the first on the `veined` theme: near-black basalt with mint-cyan mineral veins, matching the game's own `rockVeined` boulder |

The traced maps are not hand-placed: `scripts/trace-map.py` cuts one sprite per rock out of
the upscaled image, and re-running it overwrites both the JSON *and* `assets/<id>/`. Each one
records what it came from under `traced` in its JSON — which is also how `tests/traced-check.cjs`
finds them, so the next one needs no test change. **None of them place threats**; those are the
designer's. Food is auto-placed in the roomiest open pockets.

## The pipeline

```bash
node scripts/author-three-ways.mjs   # (this map only) regenerate the JSON from its parameters
node scripts/gen-levels.mjs          # inject docs/levels/*.json into index.html
node scripts/gen-levels.mjs --check  # CI-style: fail if index.html is stale
node tests/level-check.cjs           # boot the map and assert its geometry
```

`index.html` holds the generated copy the game actually reads, between the two markers in
`__m_levels_data`. There is no build step — that inline array **is** the build — so edit the
JSON here and re-run `gen-levels.mjs`; never hand-edit the array.

Upstream authored its maps in a GUI (`docs/level-editor.html`) that did not come across with
the fork, so `three-ways.json` is generated by a parametric authoring script instead. If you
hand-tweak the JSON, know that re-running that script overwrites it — move the change into the
script if you want it to stick.

## Claiming a campaign slot

`campaignLevel: null` means the map changes nothing about the campaign and is reachable only by
id. Set it to a number and that campaign level's generated map is replaced, in **both** modes
(there is no per-mode authored map — `layout`/`objects` are geometry, and geometry is shared).
`gen-levels.mjs` refuses two maps claiming the same slot.

## Things that bite

- **Rock is not baked into cells.** Rock objects are published on `sub.levelSprites`, and
  collision is stamped at render time from each sprite's *alpha* into a 9 px mask
  (`solidifyRock`). A wall is only as solid as its thinnest continuous band — so walls want
  overlapping courses, and any claim that one is sealed needs a flood-fill test, not a reading
  of the JSON. `tests/level-check.cjs` does this.
- **Food and water punch holes through rock.** The solidify pass skips cells that hold food or
  water, so a pile or a reservoir overlapping a wall opens it. Keep a row of clearance.
- **Water must be listed before food.** `buildLevel` walks `objects` in order and `stampFood`
  yields to cells that are already water; the other order lets a pile eat the pool.
- **`pathClear` beats rock.** The entry (cols 0..startCols) and goal (last goalCols+1) channels
  are dug clear and forced passable, so a sprite drawn over them reads as an invisible hole.
  Stop walls short of the goal channel.
- **Ant nests path before rock exists.** `placeAntNests` runs its BFS at build time, when the
  mask does not exist yet, so a nest whose nearest food is far away can plot its first trail
  straight through a wall. Put a nest over the food you want it to work.
- **Threat counts come from the map, not the campaign.** Authored spawns are placed exactly as
  listed; the campaign's per-level table only sets the respawn ceilings. A map plays the same
  in whatever slot it occupies.
